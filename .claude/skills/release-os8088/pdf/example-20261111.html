os8088 v1.0.20261111

11 November 2026 · commit 40d0df1 · kernel 105,636 bytes

os8088 is a graphical operating system for the original IBM PC, written in 8086 assembly and started from a floppy disk. It has overlapping windows, a mouse and programs you can run side by side.

This release teaches PageDesk, its PDF viewer and editor, to read PDFs as they are made today. Until now most PDFs written since 2003 had to be rewritten on a modern computer before PageDesk would open them. It now opens them on the machine itself, including encrypted files, fonts stored inside the file and JPEG pictures.

What's new

PageDesk reads PDFs as they are made today #354

PDFs made since 2003 usually pack their index into compressed blocks, and many are encrypted, carry their own fonts or hold JPEG pictures. PageDesk now reads all of these itself: compressed and damaged indexes, encryption up to AES-256 with a password prompt, embedded fonts, JPEG, JPEG 2000, JBIG2 and fax-style pictures, every colour space, shadings and transparency. On an emulated 4.77 MHz IBM PC a plain page appears about 50 seconds after the double-click.

PageDesk is two disks on a 360KB machine #354

Its 360KB disk now holds the program alone, and a second disk carries the sample PDFs and the README. Keep the program disk in the drive; if it is out, PageDesk asks for it back.

Good to know. The software disks are byte for byte the same as last release; the system disks differ only in their build number. PageDesk is on its own disk, the everything sets and the live USB and CD, and no longer needs the os88pdprep.py tool.

Spotlight

PageDesk, a PDF reader for the IBM PC/XT

A PDF reader and editor for a 4.77 MHz IBM PC/XT with 640KB and no maths chip. It opens PDFs as they are made today, with their own fonts, pictures and passwords, and saves your highlights and notes as a PDF any other reader opens.

What a PDF is

PDF is the format most manuals, papers and forms are handed around in. Adobe published it in 1993, ten years after the IBM PC/XT, so no program of the XT's day could read one. A PDF describes each page as a list of drawing instructions: put this text here in this font, draw this line, place this picture. It also carries an index of where each part starts, so a reader can jump to page 400 without reading the 399 before it.

The format has grown since. Files made since 2003 usually pack that index into compressed blocks, and many carry their own fonts, photographs or a password. When PageDesk first shipped it read only the older form. It now reads them itself.

What it reads

Today's files

Compressed indexes, files that mix old and new forms, and files whose index is damaged, which PageDesk rebuilds by scanning the file.

Passwords

RC4 and AES encryption up to AES-256. A locked file asks for its password, and a save keeps the copy locked with the same key.

Fonts

TrueType, Type 1, CFF and Type 3 fonts stored in the PDF are drawn from their own outlines. Search and Copy use the real text.

Pictures and colour

JPEG and JPEG 2000 at a reduced size, JBIG2 and fax scans, every PDF colour space, smooth shadings, patterns and transparency.

An XT cannot hold all of that at once. Each kind of decoder is a separate piece that PageDesk reads from the disk only when a page needs it. On a machine with memory above 640KB the pieces stay there after their first use.

Pictures

Taken from this build in QEMU, an emulator that is far faster than an XT, so they say nothing about speed. VGA unless noted.

Every screen

PageDesk runs on VGA, EGA, CGA and Hercules, the monochrome card from 1982. Colours are turned into patterns of dots where a screen has only black and white, and the window lays itself out to fit a short CGA screen with one bar of controls.

Marking up

Highlights, sticky notes, text boxes, freehand drawing, lines, boxes and ellipses, and page changes. PageDesk never writes into the file it opened: Save As writes a copy with your changes added at the end, which other PDF readers open.

How fast it is

Measured on MartyPC, an emulator that runs an IBM PC at its real speed, cycle for cycle: a 4.77 MHz 8088 with 640KB and PageDesk on a 720KB floppy. Each time runs from the double-click on the file to the first page on screen; about 30 seconds of it is PageDesk loading from the floppy. Where two times are given, the first is on CGA and the second on Hercules.

What it cannot do yet

PageDesk draws as much of a page as it can and says on its status line what it left out. On a 640KB machine a large embedded font may not fit beside the other pieces, so it is drawn in PageDesk's own face instead. A coloured mark under transparency is drawn in grey, and Chinese, Japanese and Korean text has no face to draw in.

Some files are slow on an XT. While a JPEG 2000 picture decodes, the keyboard can wait up to a minute. A file locked with the newest AES-256 method takes about 21 minutes to unlock on an 8088, so PageDesk asks first, and Esc cancels. It does not fill in forms, check signatures or print.

Run PageDesk

  1. Download the release zip and start the system disk for your disk size in drive A.
  2. Put the PageDesk disk from PROGRAMS/PAGEDESK in drive B. At 360KB it is two disks: the program on the first, the sample PDFs on the second.
  3. Copy any PDF to a floppy and double-click it, or start PAGEDESK.O88 and press Sample guide. A locked file asks for its password.
  4. Keep your changes with File > Save As. Saving under the file's own name asks before it replaces it.
