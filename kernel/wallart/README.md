# Wallpaper tile art (SPEC.md 136.3)

Source art for the six built-in wallpapers, generated on 2026-11-23 with Codex
CLI 0.170.0's built-in image generation from `PROMPT.md` (verbatim). Each
design is a colour tile (`*-c.png`, 64x64 logical pixels drawn 8x enlarged,
EGA palette) and a hand-drawn mono tile (`*-m.png`, 64x32 logical, black and
white). `tools/os88wall.py` turns each pair into a `.WAL` file (SPEC.md
136.2) deterministically; nothing here is regenerated by `make`.

| design | colour | mono |
|---|---|---|
| Bricks | `bricks-c.png` | `bricks-m.png` |
| Weave | `weave-c.png` | `weave-m.png` |
| Circuit | `circuit-c.png` | `circuit-m.png` |
| Floppies | `floppy-c.png` | `floppy-m.png` |
| Waves | `waves-c.png` | `waves-m.png` |
| Stone | `stone-c.png` | `stone-m.png` |
