# Breadboard XT independent host repair verification

Core and all UI repair regressions are independently green. No product edits, target builds, emulator
rows, soak or test-full were performed by this verifier in this stage.

Owned files: apps/breadxt/hosttest/{coretest.c,uiglasstest.c,README.md},
tests/{breadxt_core.py,breadxt_ui_host.py}. export.c belongs to another owner.

## Commands and results

    six independent expected-answer negative controls fail as intended

The independent Python oracle uses Cholesky rather than the implementation's
elimination. Returned rounded branch currents also satisfy KCL with a per-branch
rounding allowance; exact output cardinality is checked. Three actual-output
corruptions (voltage/current/source direction) are rejected as negative controls. Source current is deliberately passive pin1-to-pin2: supplying
negative, capacitor backdrive positive. The graph oracle calculates delivered
current and compares actual source current against its negative.

New fixtures cover B-only20ms clock capture with steady A; dominant555 reset
with floating comparators; isolated/open-switch LED FLOAT with0 current; true
R/C references; two-series-LED conduction and reactivation after a clock-dark
step; weak near-threshold/high-R references; real limiter vs none vs parallelR;
one-source class refusal; an actually primed NAND feedback event exhaustion;
metadata dirty/restore without invalidating live results; clean New/add/Undo;
and read-only next-history Add/Delete/Undo/Redo sides.

The UI harness runs actual callbacks with real-SDK declarations generated by
removing only target-inapplicable layout assertions. A clipped opaque glass
models native clipping and compares delta paints byte-for-byte with full paints.
Wide cases retain editor content and check uncovered LED/scope/bar both while
editing and after Esc. Locate covers already-visible Help/compact Scope and
panned-offscreen targets; no-location requires actual visible feedback, not
merely a string in bu_msg. It now verifies the native no-location toast.
The stale case uses real callback rotate edits around a failed solve, calls the
public compiler without solving, rejects old status/location and proves a fresh
failed solve remains locatable. The scope case rejects diagonal interpolated
edges for both channels and verifies Pause redraws the header immediately. Its negative control clears the revision latch. Queue sends Enter then Esc before wake and additional
callbacks while the accepted payload is pending.

## Evidence limits

The host uses actual16-bit stored words, but native IEEE-double adapters and
host locals. It does not prove target integer promotion, opaque numeric bridge,
SS/DS addressing, SDK trampolines, stack, assembly band helpers, real fonts,
monochrome raster, file dialogs or4.77MHz cost. Renderer-input injection tests
painting, not whether injected numeric values came from a real solver commit.
HCMID must run on actual8088 to catch the old5000*7 signed-threshold overflow.

Strict kern_mega runtime remains a separate target check. No local Bochs or
automation-enabled86Box instrument is available; QEMU is not a substitute for
protected-mode segment checking. Parent owns the final capability report.
