You are designing UI mockups for os8088, a Macintosh System 1 / early-Windows style GUI operating system for the IBM PC, written in 8086 assembly. Use your built-in image generation tool. Save every image as a PNG in the current working directory with the exact file names given below. Do not write any other files.

We are adding a JOYSTICK driver: one shared driver for the PC game port (I/O port 201h), set up once in the Control Panel, that every game then reads. It is modelled on three classics: Windows 3.1's Joystick control panel applet (Calibrate and Test), Linux's analog joystick driver with jscal calibration and a dead zone ("flat"), and OS/2's GAMEDD game port driver (calibration, dead zone, button press counters). The Control Panel gets a new page, "Joystick", that the driver owns. It must be designed for BOTH faces of the Control Panel, shown in the attached screenshots of the real, running OS:

- `vga-640x480-drivers.png` and `vesa-800x600-drivers.png`: the WIDE face (VGA 640x480 and VESA 800x600). A large window: grouped page list with 16x16 icons on the left (SYSTEM / HARDWARE / APPEARANCE), a header strip with the page's 32x32 icon, its title and a one-line description, the page area, and a light grey status line at the bottom. The Joystick page appears in the HARDWARE group, after Sound.
- `ega-compact-drivers.png` (EGA 640x350, colour) and `cga-compact-drivers.png` (CGA 640x200, black and white only): the COMPACT face, a 320x151 window with a text-only page list on the left and a small page of about 221x121 pixels on the right. "Joystick" is a row in that list. Everything on the compact page must fit 27 characters by 13 rows of an 8x8 font.
- `cp-drivers-vga-640x480.png`: the original design mockup of the wide face, for its design language.

Hard visual constraints - the mockups must look like something this OS can really draw:
- ONLY the 16-colour EGA/VGA palette: black, blue #0000AA, green #00AA00, cyan #00AAAA, red #AA0000, magenta #AA00AA, brown #AA5500, light grey #AAAAAA, dark grey #555555, light blue #5555FF, light green #55FF55, light cyan #55FFFF, light red #FF5555, light magenta #FF55FF, yellow #FFFF55, white. The CGA mockup uses ONLY black and white (greys become dither checkerboards). No gradients, no anti-aliasing, no blur, no transparency.
- Text is a fixed-width 8x8 pixel bitmap font, bold and blocky exactly like the screenshots. Every glyph is 8 pixels wide. Pixel-crisp.
- Lines are 1 pixel. Buttons, check boxes (12x12), radio buttons (12x12), group boxes with a light grey title band, tabs and scroll bars exactly in the style of the screenshots. Reuse the screenshots' chrome, menu bar, desktop and dock exactly; change only the page area and the selected list row.
- Render each mockup at the REAL screen resolution, 1:1 pixels.

What the Joystick page shows (wide face):
- Header strip: a 32x32 joystick icon (a black base with a red ball-top stick and a red fire button), title "Joystick", description "Calibrate and test the game port joystick."
- Two POSITION boxes side by side, titled "STICK A" and "STICK B": each a square plot about 110x110 pixels, white with a light grey crosshair and a dashed dark grey dead-zone square in the middle, and a solid blue 5x5 dot where the stick is now. Under each: "X  +34" and "Y  -12" (the calibrated value, -127..+127) with the raw count in dark grey ("raw 412"), and round button lamps labelled 1 and 2 (A) / 3 and 4 (B): lit light green when pressed, dark grey when not. Stick B, when the controller type has no second stick, is drawn greyed with "Not used by this controller type". When no stick answers, the box says "Not connected" in dark grey.
- A group "CONTROLLER" with radio buttons: "2-button joystick", "Two 2-button joysticks", "4-button joystick", "Flight stick (throttle, rudder)", "CH FlightStick Pro (hat)", "ThrustMaster FCS (hat)". For the flight stick types the STICK B box becomes two vertical bars, "Throttle" and "Rudder", and a small 8-way hat indicator.
- A group "SETTINGS": "Dead zone" with [-] 8% [+]; check boxes "Invert Y axis", "Swap sticks A and B"; and the line "Game port: stick A found, stick B not connected - 1.1 ms a read".
- Buttons: [Calibrate...] [Reset calibration] [Test games...] is NOT needed - just [Calibrate...] and [Reset].
