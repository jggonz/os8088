# Keyboard screenshots

Captured from the current built keyboard implementation, whose final core
source is `c8a3160b9`. Later changes are tests/documentation and the upstream
Wire package update, which changes no pictured code. The final byte hashes
are in `docs/reports/keyboard-final.json`.

`keyboard-*` shows the new Control Panel page; `text-*` shows physical input
from Spain, Latin American Spanish and French layouts in Note Pad. VGA,
CGA and Hercules captures use the verified patched MartyPC recorded in
`docs/reports/keyboard-instruments.json`; `text-mega.png` uses Bochs with
kern_mega. Every image is a direct emulator capture. The PR links these
files at their committed SHA.

No physical international keyboard or reference Windows application run
is represented by these pictures.
