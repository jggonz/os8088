# Borat audio-source research and local candidates

Research date: 2026-11-20. No fetched audio is checked into the repository or
permitted into the distributable package. Source pages, actual MP3 downloads,
ffprobe output, converted WAVs, import manifests and SHA-256 metadata are held
in the integration session's external voice-candidates evidence directory.
The table records actual fetched files, rather than search snippets.

The [official Prime Video trailer](https://www.youtube.com/watch?v=0Rsa4U8mqkw)
was found as an identifiable promotional source; no isolated reusable clip or
redistribution grant was established there. The soundboard pages below supplied
actual playable MP3 resources. This identifies source material but **does not
establish permission to distribute movie/television performances**.
The [Myinstants terms](https://www.myinstants.com/en/terms_of_use.html) reserve
rights and limit general access to personal noncommercial use; the
[copyright policy](https://www.myinstants.com/en/dcma_copyright_policy.html)
provides takedown procedures. A download button and uploader credit do not
clear underlying Borat/Sacha Baron Cohen material for this game's release.
No permission was requested and no release licence was found. All clips below
therefore remain **local evaluation only, redistribution unestablished**.

The first 9 rows meet the approximately 3-second short-clip target by container
duration, but some are alternate performances of the same phrase. Coverage of
a distinct laughter/poor-result clip remains unverified. The extended clips
were fetched and inspected technically, then rejected from the working set.
Titles are source labels, not independently verified transcripts.

Technical inspection succeeded: ffprobe identified MPEG audio streams;
ffmpeg decoded nonempty PCM; the converter rejected silence, bounded peaks,
trimmed only exterior silence and produced valid source/hash sidecars. The
8 kHz working set contains greeting and clipped success (22,656 bytes);
the 6 kHz set adds the brief error reaction (22,712 bytes). These local test
packs are deliberately external and are not automatic build inputs.

The host's `afplay` was invoked on the two converted 8 kHz clips and returned
exit 0. **This agent has no audio-input/listening tool and cannot attest that
it heard or subjectively verified the clips.** The file labels/captions remain
provisional until a person listens. There is no claim of completed audition,
verified spoken transcript, guest PCM audibility or sound quality. A guest
Sound Blaster capture with the imported pack and actual listening is still
required. Speaker beeps and original on-screen captions do not pass that test.

Clip speech is kept separate from original written roasts. For example the
local error clip has its own provisional short spoken caption; the original
performance roast is displayed as a written joke, with the audio labelled as a
reaction. There is no claim that the character spoke the original roast.
