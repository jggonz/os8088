# megaport-candidates.txt - soak rows worth porting to kern_mega under Bochs
# COMPLETED (2026-10-26): the selection behind tests/megaport.txt, which now
# carries ~317 ports; kept as the record of what was chosen and excluded.
# (build/mega.img + build/megaapps.img, Bochs 386 VGA, PS/2 mouse, 16MB,
#  optional SB16 / NE2000), chosen against rows.json (1135 rows) plus the
#  emulator rows rows.json does not list (sndmove, drvmove, regapp, regwork,
#  regpin, fmrefuse, btn*, gifdrag, thewire, int0sweep, weavesmoke, kd*hand,
#  kdreturn) - suite.py registers those without needs=("marty",).
#
# Grades:
#   A  os88ui verbs + plain kernel-symbol reads; runs unchanged once the shim
#      maps boot(SYS, apps=...) to mega.img and honours an apps= FIXTURE
#      floppy as B: (most DOS gate rows are A on that convention)
#   B  small edits: machine name (herc/cga default -> Bochs VGA), a 1bpp
#      m.vram()/640x200 geometry assumption -> VGA fbuf, `seg << 4` on a
#      package region/claim -> selector-aware readseg, m.disk() used only as
#      a "disk went quiet" quiesce (needs a Bochs stand-in), a package that
#      is on office360/games360 rather than megaapps.img, breakpoints in
#      PACKAGE code (selector:offset, not seg<<4+off)
#   C  important, needs real rework: the scenario is built on the
#      conventional-heap / mem_tab layout (kern_mega's claims are LDT
#      selectors in a pool), or the row drives tests/os88qemu.py's raw
#      QMP/HMP layer instead of the Marty API, or the assertion inverts
#
# Flag noise worth knowing: rows.json's `flick` flag is almost always
# os88marty.pace(m, secs) - a GUEST-seconds sleep the shim must provide -
# not the flicker instrument. Only brscroll, calcflick, deskbench,
# drvscroll, ftpdflick, lemplaymarty, tank, tmground, weavegame and
# wireflick call m.flicker()/m.pace(frames)/frame_count(); none is chosen.
# Likewise `cyc` is usually os88marty.until's guest-seconds budget.

# - Solitaire: no functional row exists at all (only regapp's declaration
#   check and megasweep's launch).
# - Calculator: dispcalc is its only functional row and it is an
#   extended-desktop/1bpp row; calcflick is a flicker row. regapp covers
#   CALC's movable declaration only.
# - RunCPM / CP/M programs: no functional row beyond rcmove (a heap move)
#   and call5 (which is DOS's CALL 5); rczex/rcz80test are make targets in
#   raw QEMU, not soak rows.
# - ModPlug and Piano: no rows.
# - Frotz functionally: only megafrotz (covered), zrestart and
#   editmove-frotz (heap); zcheck/zgfx are make targets.
# - RTC write: no QEMU RTC-write row is registered; dtwrite (marty) is the
#   nearest and needs its assertion extended to read Bochs's CMOS.
