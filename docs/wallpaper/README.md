# Desktop wallpaper mockups (SPEC.md 136)

The design reference for the Control Panel's Wallpaper page, generated on
2026-11-23 with Codex CLI 0.170.0's image generation from `MOCKUP-PROMPT.md`
(verbatim), with screenshots of the wide (`docs/cpwide/shots/vga-640x480-theme.png`,
`docs/cpwide/cp-theme-vga-640x480.png`) and compact
(`docs/cpwide/shots/cga-compact-drivers.png`, `ega-compact-drivers.png`)
panels attached. Each is at its screen's real resolution, 1:1.

| file | face | screen | wallpaper shown |
|---|---|---|---|
| `wall-wide-vga-640x480.png` | wide (SPEC.md 136.7) | VGA 640x480 | Bricks |
| `wall-wide-vesa-1024x768.png` | wide (136.7) | VESA 1024x768 | Circuit |
| `wall-compact-ega-640x350.png` | compact (136.8) | EGA 640x350 | Waves |
| `wall-compact-cga-640x200.png` | compact (136.8) | CGA 640x200, 1bpp | Bricks, mono |

They are a design, not a screenshot: where the built pages differ, SPEC.md
136.7 / 136.8 say why. The extra gallery entries (`GRID.WAL`, `DOTS.WAL`, ...)
stand for wallpapers a user added; they are not shipped.
