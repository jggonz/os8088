# Retro-site browser screenshots

These captures document the Browser's lightweight rendering on live retro-web targets and its 1.3 text-formatting milestone. The live-site examples were captured in 86Box; the formatting fixture was checked in QEMU.

- [The Old Net lite homepage](oldnet-lite.png)
- [TinkerDifferent forum](tinkerdifferent-forum.png)
- [Browser 1.3 text formatting in QEMU](browser-1.3-formatting.png)

The Browser intentionally presents a text-first view: tables provide structure, links remain selectable, and unsupported styling and scripts do not need a full graphical layout engine. Browser 1.3 adds bold, italic, underline, heading, list, blockquote, and preformatted-text handling using the existing cell font.
