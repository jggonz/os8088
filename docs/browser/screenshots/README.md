# Retro-site browser screenshots

These 86Box captures document the browser's lightweight rendering on live retro-web targets. They show the Old Net's minimal homepage and the TinkerDifferent forum's text-and-table layout.

- [The Old Net lite homepage](oldnet-lite.png)
- [TinkerDifferent forum](tinkerdifferent-forum.png)

The browser intentionally presents a text-first view: tables provide structure, links remain selectable, and unsupported styling and scripts do not need a full graphical layout engine.
