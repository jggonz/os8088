# Byteopoly - the uplifted centre panels as kit scenes (SPEC.md 131.9.12,
# 133.6-133.7). Lane: panels A. IDs 420..429 (art2.h BP_A2_SC_PANA): each
# panel is an even ID for FULL (the centre 336x300) and the next odd ID for
# MID (384x204); COMPACT is drawn by code. Origin = the centre's top-left.
#
# Conventions every scene here keeps (bp_panels.c ovl_gp_scene):
#   %0 is always 0: "if %0" marks a PLACEHOLDER, an op never drawn whose
#      rect a button takes - tag = the button's key ('b' 98, 'a' 97, 'p' 112,
#      ' ' 32, 'e' 101, 't' 116, 'm' 109, 'r' 114, 'c' 99, 'l' 108, 'd' 100,
#      'x' 120, 'u' 117, Esc 27), +128 while a confirmation shows. The C draws
#      the buttons there (gk_button), so a button, its key and its mouse rect
#      are one table.
#   %1 is 1 when $1, the status line (a refusal, "Sent - waiting", "Waiting
#      for NAME on the other PC"), has something to say.
#   #200 is the panel's rect (damage, clicks); #201 the status line's.
#   Money slots arrive with " cr" on them.
