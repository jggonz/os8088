# Writing in ArtfulType

A distraction-free writer. Press **New** or **Open** on the card, and the
whole screen becomes the page: no window frame, no dock, no desktop --
only the words and a menu bar that appears when you reach for it.

Press *Esc* at any time to hand the screen back. Your document survives
the trip and re-enters exactly as you left it.

## Marking up as you type

This file is markdown, and it is also a demonstration of it. Everything
below is written the way you would write it, and shown the way Writer
mode renders it.

A heading is a line beginning with a hash. One hash is a title, two is a
section, three is a subsection -- and asking for the level a line already
has takes it off again.

Inside a line, wrap a phrase to change it:

**Two stars either side make it bold.** *One star makes it italic.*
`Back-ticks set it as code.` ~~Two tildes strike it through.~~

Square brackets and round brackets together make a link, as in
[the os8088 project](http://os8088.com) -- the address stays hidden
while you write elsewhere, and appears when the caret steps inside it.

## Two views of the same file

Writer mode scales the headings and hides the marks. Markdown mode shows
you every character that is really in the file, at one size. The document
does not change between them -- only what is drawn does -- so you can
switch as often as you like and lose nothing.

## The things worth knowing

Undo goes back many steps, and redo comes forward again. Selection works
by dragging, and there is a clipboard of the app's own. Two zoom sizes
are offered, because 640 pixels of screen is not many when the face is
comfortable to read.

Open and Save go through the standard file dialog, so a document written
here is an ordinary file on an ordinary floppy: something another program
on another machine can read, forty years either way.

## Now delete all of this

It is a sample, and the best thing you can do with a sample is replace
it. Select all, type over it, and save it under a name of your own.
