Its manual, in its own dialect.

Opening a page

  • Double-click a .HTM: the extension is this package's, so the file opens the program.
  • File > Open — another off the floppy.
  • File > Open Location — fetch one. The bar opens holding http://, the only scheme there is; type the rest and press Return.

What it refuses, and why

Https is not supported
RSA-2048 is minutes at 4.77 MHz, so the scheme is refused by name, not hung on: try one.
Relative link: this page has no server
A page off a floppy has nothing to be relative to: try one.
Page truncated
32 KB of source, 200 links, 8 table columns, 4 fields. A page cut at a ceiling says so.

Reaching the modern web

It is all behind TLS, and two screens of text arrive as 200 KB of markup. Both live on the desk machine:

    python3 tools/os88proxy.py     # serve on 0.0.0.0:8088

It ends the handshake and strips the page to what this reads, inside those ceilings. Then: Open Location, that machine's address and port — 192.168.1.50:8088 — Return.

Optional: a floppy page, or an http:// host on your own network, needs none of it.
