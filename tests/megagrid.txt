# Under kern_mega's protected mode only a multiple of 8 paragraphs is an
# identity selector, so a segment built by one-paragraph arithmetic faults or
# loads an LDT alias of other memory. A file here may not GROW, and a count
# that falls must be lowered in the same commit. The SDK rule is apps/
# os88api.inc's: normalise to EIGHT paragraphs (`and si, 127`), never one.

# --- kern_mega's DOS.O88 says OS88_HIGH (KERN-MEGA-PLAN 14.44), which brings
#     apps/dos/ into scope: its five sites are NOT in the part that says it
