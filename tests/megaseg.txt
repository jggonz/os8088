# tools/os88megaseg.py measures them off the two maps. `make mega` fails when
# the figure is above the number below. Every byte here is a byte kern_big can

# that has to run in REAL mode after the switch - the reflection's window, the
# 286 reset landing, the drop into DOS - or for data a shared routine reads
# through DS. Code that runs only in protected mode belongs in `.mega`.
