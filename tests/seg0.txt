# tests/seg0.txt - segment 0 in DS or ES (docs/plans/KERN-MEGA-PLAN.md 10.1 item 11)
#
# Real mode reads the IVT and the BIOS data area through segment 0 and a
# linear offset. In 286 protected mode 0 is the NULL selector: loading it is
# legal and the first access through it is #GP(0) - and QEMU does not fault on
# it, so no emulator here can find one of these. tests/unit/t_seg0.py counts
# the loads on the arms kern_mega assembles and holds them to this list: a file
# not in it may have none, and a count may neither rise nor be left too high.
# MEGA_SEG0 (kernel/kernel.asm) is the conversion.
#
# ONE LINE PER FILE: <sites> <path>  # <reason>
