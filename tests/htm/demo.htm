os8088

A Macintosh System 1-style GUI operating system
for the Intel 8086, in real-mode assembly

Served over plain HTTP, on purpose — see below.

What it is

os8088 is a pre-emptively multitasking, windowed operating system that boots from a single 360 KB floppy and runs in 256 KB of RAM. It is written entirely in NASM real-mode assembly, targets the 4.77 MHz Intel 8088, and drives VGA, Hercules or CGA from one binary — the adapter is probed at boot and can be changed while the machine runs.

It has overlapping windows, a serial mouse, a bottom dock, a file manager, loadable device drivers and loadable software packages that run as closable, multi-instance applications. This page is being read on it.

The machine it is calibrated against

Every performance figure in the project comes off one machine: an IBM PC 5150, kept entirely period on purpose.

An int 13h call costs one to two disk revolutions whatever it moves, so disk work is costed in calls and never in sectors.

What a drawing call costs

The single most important number in the project, and the one nothing in it believed until it was measured:

A redraw is priced by how many primitive calls it makes, not by how many pixels it covers. That sentence is why this browser scrolls by moving the pixels it already has instead of lettering them again.

Software that ships with it

  • Note Pad — wrapping, scrolling, find and replace, undo
  • Paint — a bitmap editor with BMP and GIF codecs
  • Tracker and ModPlug Player — two MOD players, two interfaces
  • Solitaire, Minesweeper, Arkanoid, Missile Command, Cyclone
  • Word — reads and writes real .DOC files
  • Frotz — a Z-machine, so the machine plays Infocom games
  • TeXPad — typesets to PDF and PostScript

Getting it

  1. Download the 360 KB image
  2. Write it to a real floppy
  3. Put it in drive A: and turn the machine on

The toolchain is nasm and python3 and there is no linker anywhere — every binary is a flat nasm -f bin image.

    ; the boot sector relocates itself to the top of memory
    int   12h                 ; KB of conventional RAM
    mov   cl, 6
    shl   ax, cl              ; paragraphs
    sub   ax, 32              ; ...less our own 512 bytes
    push  ax                  ; 8086 has no push imm
    push  word .there
    retf

Why this page is plain HTTP

A TLS handshake is public-key arithmetic, and an RSA-2048 private operation on a 4.77 MHz 8088 with no multiplier worth the name is minutes. So this machine cannot reach an HTTPS site at all, and this page is served without it so that it can.

Links that leave for HTTPS are kept here on purpose, so the browser has something it must politely refuse: an https link — clicking it should say why, not hang.
