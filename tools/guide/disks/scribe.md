## Using this disk

Scribe, the word processor, on a floppy of its own. Start os8088 from the
system disk of the same size in drive A, then put this disk in drive B and
double-click **B:**. Double-click **SCRIBE.O88** to start it, and open a
document with **File > Open...**.

## What is on it

- **SCRIBE.O88**: the word processor. See [[SCRIBE.O88]].
- **SCWELCOM.RTF** and **SCWELCOM.DOC**: two copies of Scribe's welcome
  document, one in RTF and one in Word's own format.
- **DOCS**: an empty folder for your own documents. Leave the disk writable
  so Scribe can save there.

Double-clicking a `.DOC` file opens Microsoft Word, not Scribe. Open your
documents from inside Scribe.

Every size carries the same files.
