## Using this disk

Programs a 360KB machine runs to look at itself rather than to get work done.
Put it in drive B and double-click **B:**.

- **SYSCHECK.O88**: System Check, which checks a system disk or a hard disk
  against this release. At 360KB it is on this disk and on no other.
- **REDLINE.O88**: the benchmark that scores your PC against a 4.77 MHz IBM PC.
- **TASKMGR.O88**: a copy of the Task Manager.

`SYSTEM/DOS` holds two programs for a PC running MS-DOS, not for os8088: the
far end of the cable link and the tool that splits a large file across
floppies. Copy them onto the DOS machine.
