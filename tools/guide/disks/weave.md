## Using this disk

Weave runs small web-style apps, each one a single `.WAB` file. Start
os8088 from the system disk of the same size in drive A, then put this disk
in drive B and double-click **B:**. Open the `WEAVE` folder and
double-click **FORM.WAB**, **SHEET.WAB** or **PONG.WAB**. See
[[WEAVE.O88]].

## What is on it

- **WEAVE**: the runtime, **WEAVE.O88**, and the three demo apps: a form, a
  spreadsheet and a Pong game.
- **LOOM**: Loom, the editor that builds apps on this machine, and the
  source files of the three demos. See [[LOOM.O88]].
- **CATALOG.TXT**: what every file on the disk is.
- **SYSTEM/APPDATA**: where the programs keep their settings. Leave the disk
  writable.

A 640KB machine runs four or five small apps at a time. A 256KB machine
runs one.

Every size carries the same files.
