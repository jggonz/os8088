## Using this disk

Use this disk in place of the ordinary system disk when os8088 runs in an
emulator or a virtual machine. Its pointer follows your real mouse straight
away, without the emulator capturing it first.

Put it in drive A with the 1.44MB software disk (`apps.img`) in drive B.
There is no separate software disk for it.

> The pointer needs an emulator that offers the VMware mouse, which a 386 or
> later can talk to. On a real PC, or an emulated XT, use the ordinary system
> disk.
