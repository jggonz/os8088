## Using this image

The whole system and every program on one bootable hard-disk image. Write it
to a USB stick, start a PC from the stick (a PC with a legacy BIOS, or a
modern one set to legacy or CSM boot), and os8088 starts with the stick as
drive C:.

The Disk imager in the Tools tab writes the stick on a Mac and checks every
byte. On another system, any raw image writer works.

Settings and the files you save are kept on the stick.
