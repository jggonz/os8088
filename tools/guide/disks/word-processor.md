## Using this disk

Microsoft Word 1.1a on a floppy of its own. Start os8088 from the system
disk of the same size in drive A, then put this disk in drive B and
double-click **B:**.

Double-click **WORD.O88** to start Word with an empty document, or
double-click **WELCOME.DOC** to open Word with the welcome document already
loaded. Any `.DOC` file opens in Word when you double-click it.

## What is on it

- **WORD.O88**: the word processor. See [[WORD.O88]].
- **WELCOME.DOC**: a welcome document to read and try things on.
- **DOCS**: an empty folder for your own documents. Leave the disk writable
  so Word can save there.

Every size carries the same files.
