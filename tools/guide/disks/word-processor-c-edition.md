## Using this disk

The C edition of the word processor, on a floppy of its own. Start os8088
from the system disk of the same size in drive A, then put this disk in
drive B and double-click **B:**.

Double-click **CWORD.O88** to start it, then use **File > Open...** to open
**WELCOME.RTF**, the welcome document beside it. Once the program has run,
double-clicking an `.RTF` file opens it in the C edition.

## What is on it

- **CWORD.O88**: the word processor. See [[CWORD.O88]].
- **WELCOME.RTF**: the welcome document.
- **DOCS**: an empty folder for your own documents. Leave the disk writable
  so the program can save there.

Every size carries the same files.
