## Using this disk

PaccMan, the arcade Pac-Man, on a floppy of its own. Start os8088 from the
system disk of the same size in drive A, then put this disk in drive B and
double-click **B:**. Double-click **PACCMAN.O88** to start it. See
[[PACCMAN.O88]].

## What is on it

- **PACCMAN.O88**: the game.
- **README.TXT**: the game's keys, menus and scoring, and where it came from.

PaccMan plays at full arcade speed on a 386. On a 4.77 MHz PC or XT it runs
at about a quarter of that speed, and is still playable.

Every size carries the same files.
