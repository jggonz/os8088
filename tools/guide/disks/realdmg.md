## Using this disk

A Game Boy for your PC, on a floppy of its own. Start os8088 from the system
disk of the same size in drive A, then put this disk in drive B and
double-click **B:**. Open the `REALDMG` folder and double-click
**GBDEMO.GB** to see the demo, or **REALDMG.O88** to start RealDMG and load
a game of your own with **Machine > Load Game...**. See [[REALDMG.O88]].

## What is on it

The `REALDMG` folder holds the program:

- **REALDMG.O88**: RealDMG, the Game Boy emulator. It plays original Game
  Boy cartridges saved as `.GB` files, in a window or on the whole screen.
- **GBDEMO.GB**: the project's own demo cartridge, a bouncing ball and a
  clock. See [[GBDEMO.GB]].
- **README.TXT**: notes about the program and its keys.

The `SYSTEM` folder holds an empty `APPDATA` folder, where RealDMG keeps
your keys and each game's Speed and Sound settings once you change them.

No commercial game is on the disk. Bring your own cartridges: copy them to
any disk and double-click one. The rest of this floppy has room for a few,
and RealDMG writes each game's saves beside it.

RealDMG plays on an 8088, and the demo runs at full speed there, but a busy
game runs slowly on one. On a 286 or better RealDMG can translate a game
into the PC's own instructions, and most games run near full speed. A Sound
Blaster or AdLib plays all four of the Game Boy's sound channels; without
one the PC speaker plays the louder of the two square-wave channels.

Every size carries the same files.
