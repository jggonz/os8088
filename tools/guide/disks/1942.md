## Using this disk

1942, the arcade shooter, on a floppy of its own. It comes in two sizes,
1.44MB and 360KB. Start os8088 from the system disk of the same size in
drive A, then put this disk in drive B and double-click **B:**.
Double-click **1942.O88** to start it. See [[1942.O88]].

## What is on it

- **1942.O88**: the game, with its pictures, scenery and sounds inside the
  one file.
- **README.TXT**: the notes on the game.

The game needs a VGA or a colour CGA display. On a Hercules or other
black-and-white display the window opens but the game does not start.

Both sizes carry the same game.
