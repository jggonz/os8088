## Using this disk

Put the software disk in drive B (in an emulator, the second floppy drive)
after the system has started. Double-click the **B:** icon on the desktop to
open it, then a folder, then a program.

Double-clicking a document also works: os8088 knows which program opens
each kind of file, on any disk.

## What is on it

- **APPS**: the everyday programs.
- **GAMES**: the games.
- **MEDIA**: sample documents, pictures, music and video to open.
- **SYSTEM**: settings the programs on this disk start with, and in `DOS`
  two small tools to copy onto a PC running MS-DOS.
