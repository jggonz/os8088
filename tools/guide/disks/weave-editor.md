## Using this disk

Loom, the editor that builds Weave apps on the machine itself. Start os8088
from the system disk of the same size in drive A, then put this disk in
drive B and double-click **B:**. Open the `LOOM` folder and double-click
**FORM.WML**, **SHEET.WML** or **PONG.WML** to open a demo's sources in
Loom. See [[LOOM.O88]].

## What is on it

- **LOOM**: **LOOM.O88** and the source files of the three demo apps. Pack
  writes a new `.WAB` beside its sources, in this folder.
- **WEAVE**: the Weave runtime and the demos, already packed, so a `.WAB`
  you build runs from this disk. See [[WEAVE.O88]].
- **SYSTEM/APPDATA**: where the programs keep their settings.

Leave the disk writable, so Loom can save and pack. Loom wants about 110KB
of free memory while you edit and as much again while it packs, which a
640KB machine has.

Every size carries the same files.
