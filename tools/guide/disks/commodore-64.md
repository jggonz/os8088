## Using this disk

A Commodore 64 in a window, on a floppy of its own. Start os8088 from the
system disk of the same size in drive A, then put this disk in drive B and
double-click **B:**. Open the `C64` folder and double-click **C64.O88**.
See [[C64.O88]].

## What is on it

The `C64` folder holds everything:

- **C64.O88**: the Commodore 64, with its BASIC, KERNAL and character ROMs
  inside the file. Copy it anywhere and it still starts.
- **README.TXT**: notes about the program.
- **COPYING**: its licence.

The machine needs 64KB of free memory for the C64's RAM. It runs very
slowly on a 4.77 MHz PC or XT and is usable on a 386 or 486.

Every size carries the same files.
