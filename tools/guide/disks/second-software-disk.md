## Using this disk

A 720KB software disk cannot hold every program, so this second one carries
what the first leaves off. Boot the 720KB system disk in drive A as usual,
then put either software disk in drive B and double-click **B:**.

## What is on it

- **APPS**: PiXEL, the image viewer and editor, and MIDIRack, the MIDI player.
  MIDIRack is on both software disks, so its songs open from either.
- **GAMES**: RealDMG, the Game Boy emulator, and DrMarco.
- **MEDIA**: RealDMG's demo cartridge, the demo video, and in `MIDI` the eight
  songs the first software disk has no room for.
- **PICTURES**: five of PiXEL's sample pictures.
