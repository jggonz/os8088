## Using this disk

The system for a machine with as little as 128KB of memory. It boots a smaller
kernel and carries every program that runs in 128KB, all on the one disk, so a
machine with one floppy drive needs nothing else. Boot it in drive A in place
of the system disk for your size.

The small system loads no hardware drivers, and has no hard-disk install. The
Control Panel, the file chooser, file copying and the formatter are read from
this disk when you use them, so keep it in a drive.

> The 720KB disk is formatted with larger clusters than a standard one,
> because the small kernel reads only a small file table. For the same reason
> a machine running it reads standard 360KB disks but no other 720KB disk. The
> 360KB disk is the standard shape.
