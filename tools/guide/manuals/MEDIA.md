# Media

`MEDIA` is the folder for documents: sample files to open in the matching
programs, and a place for your own. Double-click a file and it opens in the
program that handles it.

## Where it is

Most disks have one, each with samples that suit the disk:

- **The system disk**: the os8088 logo picture, `OS8088.GIF`, and on the
  larger sizes the logo video `OS8088.V88`.
- **The software disk**: TeXPad documents and `BROWSER.HTM`, a page for the
  Browser. The 720KB, 1.2MB and 1.44MB disks also carry the `MIDI` folder of
  songs, the tracker module `BEVERLY.MOD` and the logo video.
- **The office disk**: the TeXPad documents, a spreadsheet, a Markdown
  text, a Word document and two pictures.
- **The network disk**: `BROWSER.HTM`.
- **The music disk** and the **MIDIRack disk**: the `MIDI` songs, and on the
  music disk the module and the logo video.
- **The games disk** has an empty one.

## Using it

The first time a program shows you an Open or Save dialog, it starts in the
`MEDIA` folder of the disk the program was started from (or at the top of
that disk, if it has no `MEDIA`). After you pick another folder, that
program goes back there next time.

This makes `MEDIA` a good home for your own work. Save into it, copy files
in, or make folders inside it. The samples can be deleted if you need the
room.
