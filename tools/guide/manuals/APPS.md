# Applications

`APPS` holds the everyday programs: the editors, the tools, the players and
the utilities. Double-click a program to start it. Many can be open several
times over, each in its own window.

## Where it is

- **The system disk** carries the core programs, so a machine with one
  floppy drive still has something to work with: the DOS box, Font Viewer,
  Note Pad and Paint, plus the Browser, Telnet and the Video Player on the
  larger sizes.
- **The software disk** carries most of the rest: Artful Type, Calculator,
  Fractal, Piano, TeXPad, Tracker, Audio, Timer, Bounce, the network
  programs and more. The 720KB, 1.2MB and 1.44MB software disks add Sheet,
  Chart, MIDIRack and (except at 720KB) PiXEL.
- **The emulator system disk** and the first disk of the everything set have
  one too, and the live USB image and CD gather every program in theirs.

The office, network and games disks put their programs at the top level of
the disk instead, with no folder to open first.

## Putting things in it

You can copy programs in and out of `APPS` freely. A program runs from any
folder on any disk, and `APPS` is simply where people look for one. A program
that comes with files of its own, such as Word or the C64, has a folder of
its own instead; keep those together.

The programs keep their settings and saved state in `SYSTEM/APPDATA` on the
disk they were started from, not in `APPS`, so this folder holds programs
and nothing else.
