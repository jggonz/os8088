# Welcome document

`WELCOME.RTF` is the welcome document of the C edition of Word. It is an RTF
file, the format that edition saves, and it tells you what works: typing
and selecting, the character formats on the ribbon and the Ctrl keys, the
paragraph formats from the ruler and Format Paragraph, and a list of keys.

![The C edition with its welcome document open.](shot:cword-window)

## Where it is

At the top of the C edition's own disk in every size, and in the `CWORD`
folder of the first disk of the everything set.

## Opening it

Start the C edition ([[CWORD.O88]]) and choose **File > Open...**, then pick
**WELCOME.RTF**. Once the C edition has run, double-clicking an `.RTF` file
opens it there too.

The document only describes what an RTF file can carry back. Paragraph
formats such as centring and indents last while the document is open and
are not saved in the file, word and double underlines come back as a plain
underline, and small capitals are not kept at all. The document says so
rather than showing what the file cannot keep.
