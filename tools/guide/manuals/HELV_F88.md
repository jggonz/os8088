# Helvetica

Helvetica here is a clean sans-serif typeface with the proportions of
Helvetica and Arial: plain, even letters with no serifs. It suits headings,
notes, lists and anything that should look modern and tidy.

![Font Viewer showing Helvetica with a sample typed in.](shot:helv-f88)

## Where it comes from

This face was fitted for os8088 onto the screen's grid from Arimo, by the
Arimo Project Authors, which has the same character widths as Arial and
Helvetica. It is drawn a little heavier than regular so that most strokes are
two pixels thick. The capital `I` was redrawn with small serifs, so it never
looks the same as a lowercase `l` in a file name. The face is named for the
typeface it stands in for, Helvetica, rather than the font it was drawn from.

Arimo is under the SIL Open Font License 1.1, and so is this face.
`LICENSE.TXT` in the same folder carries the licence and the authors' credit.

## What is in it

One style of 95 characters: the capital and small letters, the figures and
the punctuation of plain ASCII. There are no accented letters. Capitals are
8 pixels tall in a 12-pixel line, with 2 pixels between lines. Letters are
4, 6 or 8 pixels wide.

## Using it

The face lives in `SYSTEM/FONTS` on the system disk. Double-click
**HELV.F88** to look at it in Font Viewer.

Microsoft Word, the C edition of Word and Scribe list it in the **Font** box
on their ribbon as **Helv**. Pick it and the whole document is shown in it;
the ribbon then names it in full, **Helvetica**.

For more words to a line in the same style, try Archivo Narrow.
