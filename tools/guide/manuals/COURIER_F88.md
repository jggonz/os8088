# Courier

Courier is the typewriter face: every character takes the same width, and
the letters have slab serifs like the keys of an office typewriter. Use it
when columns must line up, for a letter that should look typed, or for
anything you would once have written on a typewriter.

![Font Viewer showing Courier with a sample typed in.](shot:courier-f88)

## Where it comes from

This face was fitted for os8088 onto the screen's grid from Cousine Bold, by
the Cousine Project Authors, which has the same character widths as Courier
New. The bold weight was used because Courier's regular weight is famously
thin and would break up into single pixels on a CGA screen. The face is
named for the typeface it stands in for, Courier, rather than the font it was
drawn from.

Cousine is under the SIL Open Font License 1.1, and so is this face.
`LICENSE.TXT` in the same folder carries the licence and the authors' credit.

## What is in it

One style of 95 characters: the capital and small letters, the figures and
the punctuation of plain ASCII. There are no accented letters. Every
character is 8 pixels wide, so 80 of them fit across a 640-pixel screen, and
each line is 14 pixels tall.

## Using it

The face lives in `SYSTEM/FONTS` on the system disk. Double-click
**COURIER.F88** to look at it in Font Viewer.

Microsoft Word, the C edition of Word and Scribe list it in the **Font** box
on their ribbon as **Courier**. Pick it and the whole document is shown in
it.

Of the four fixed-width faces, Courier and JetBrains Mono have the tallest
lines, 14 pixels; Roboto Mono and Inconsolata fit more lines in a window.
