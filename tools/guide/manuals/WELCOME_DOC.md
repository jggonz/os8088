# Welcome letter

`WELCOME.DOC` is Word's welcome document, a one-page tour of the word
processor saved as a real Word document. Everything on it is a working
example: bold, italic and underlined text, small capitals, a centred
heading, a hanging indent, a centred and a flush-right line, a
double-spaced paragraph, and a table of useful keys.

![Word with the welcome document open.](shot:word-window)

## Where it is

At the top of the Word disk in every size, in the `MEDIA` folder of the
Office disk, in the `WORD` folder of the everything set, and in the `WORD`
folder of the live USB image and CD.

## Opening it

Double-click **WELCOME.DOC** and Word ([[WORD.O88]]) opens with the document
loaded. Most paragraphs name the key that made them, so you can put the
cursor in one and try the key yourself. Save your own documents somewhere
else, such as the `DOCS` folder, so the welcome document stays as it was.

Scribe opens it too, with **File > Open...**. A double-click on a `.DOC`
file always opens Word and never Scribe.
