# Contents

`CONTENTS.TXT` says which disk of the everything set holds which program
folders, so you can find a program without trying each disk. Its words
are shown below.

## Where it is

At the top of every disk of the everything set. The 1.44MB set and the
1.2MB set each have two disks and their own version of the file, since the
folders are split between the disks differently. Each copy marks the disk
it is on with `>` and `(this disk)`.

## Using it

Double-click it to read it in Note Pad. A program and the files it opens
are always on the same disk, so put the disk that holds the program in
drive B and open its folder.
