# Timer

Timer is a stopwatch. It counts up in hours, minutes and seconds, and you
start, stop and reset it with three buttons under the time.

![A Timer that has been running for five seconds.](shot:timer-window){full}

## Starting Timer

Open the disk that holds it, then the `APPS` folder, and double-click
**TIMER.O88**. You can open more than one Timer; each counts on its own. A
second Timer opens on top of the first, so drag it aside to see both.

Timer needs nothing special and runs on every machine.

## Timing something

A new Timer starts counting at once, from `00:00:00`.

| Button | What it does |
|---|---|
| Start | Carries on counting from the time shown |
| Stop | Stops the count and keeps the time on the display |
| Reset | Puts the time back to `00:00:00` |

![Stopped at eight seconds: Stop is greyed and Start is ready.](shot:timer-stopped){right}

The button that would do nothing is greyed: Start while the Timer is
running, Stop while it is stopped. Reset always works. If you reset a
running Timer it keeps running from zero; a stopped one stays stopped at
zero.

A button acts when you let go of the mouse. If you press a button and
then slide off it before letting go, nothing happens.

## The Timer menu

| Item | What it does |
|---|---|
| About Timer | Shows who made it. Click in the window to put it away |
| Close | Closes this Timer |

![The About card over the Timer's window.](shot:timer-about){full}

## Good to know

- The Timer keeps counting while its window is covered by another window
  or minimized. The time is right when you look again.
- Time spent stopped is not counted. Start carries on from the time shown.
- The display goes up to `23:59:59`, then starts again from `00:00:00`.
- Timer has no keys and does not save anything. Closing it forgets the time.
