# Apple II Plus

The `APPLE2` folder holds the Apple II Plus emulator and the files that go
with it:

- `APPLE2.O88`, the emulator, with the Apple's ROMs built in;
- `WELCOME.BAS`, a short Applesoft BASIC program written for os8088.
  Double-click it to start the Apple with the program loaded;
- `README.TXT`, notes on the program;
- `COPYING`, its licence.

## Where it is

On the Apple II Plus disk in all four sizes, on the everything set, and on
the live USB image and CD.

Keep the four files together when you copy the program to another disk.
