# Archivo Narrow

Archivo Narrow is a bold, narrow sans-serif typeface: plain letters with no
serifs, drawn tall and slim. Most of its letters are only 4 or 6 pixels wide,
so a line set in it holds about a fifth more text than the same line in
Helvetica. It is the face to reach for when you want a lot of words across a
narrow window.

![Font Viewer showing Archivo Narrow with a sample typed in.](shot:archivo-f88)

## Where it comes from

This face was fitted for os8088, letter by letter onto the screen's grid,
from Archivo Narrow by the Archivo Narrow Project Authors (Omnibus-Type). It
is drawn from the bold master so that every stroke is two pixels thick and
stays solid on a CGA screen. Two letters were redrawn by hand: the capital
`I` has small serifs, so it never looks like a lowercase `l` in a file name,
and the `!` has its dot separated from its stem.

The original font is under the SIL Open Font License 1.1, and so is this
face. `LICENSE.TXT` in the same folder carries the licence and the authors'
credit.

## What is in it

One style of 95 characters: the capital and small letters, the figures and
the punctuation of plain ASCII. There are no accented letters. Capitals are
8 pixels tall in a 12-pixel line, with 2 pixels between lines.

## Using it

The face lives in `SYSTEM/FONTS` on the system disk. Double-click
**ARCHIVO.F88** to look at it in Font Viewer.

Microsoft Word, the C edition of Word and Scribe list it in the **Font** box
on their ribbon as **Archivo**. Pick it and the whole document is shown in
Archivo Narrow; the ribbon then names it in full.
