# TeXPad guide

`GUIDE.TEX` is a one-page guide to the markup TeXPad understands, written in
that markup, so the source and the typeset page explain each other. It
covers the document class and paper, bold, emphasis and typewriter text,
special characters such as `\%` and `\&`, forced line breaks, quotations,
bulleted lists, a ruled table, and page layout.

![GUIDE.TEX in TeXPad: the markup on the left, the typeset page on the right.](shot:guide-tex)

## Where it is

In the `MEDIA` folder of the software disks in every size, the Office disk,
the first disk of the everything set, the video demo drives and the live
USB image and CD.

## Using it

Double-click **GUIDE.TEX** and TeXPad ([[TEXPAD.O88]]) opens with it already
typeset. Read the source on the left beside the page it makes on the right.
To try something, change the source and press `F5` to typeset it again.
Save your changes under another name with **File > Save As...** if you want
to keep the guide as it was.

For a longer example, with an abstract, sections over two pages and a
table, open [[PAPER.TEX]].
