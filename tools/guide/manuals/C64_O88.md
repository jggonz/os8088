# Commodore 64

The Commodore 64 program is a Commodore 64 in a window. It is a version of
the VICE emulator, and its window and menu bar call it **VICE**. It carries
the C64's own KERNAL, BASIC and character ROMs, so it starts the way the real
machine did, with **READY.** and a flashing cursor, and BASIC answers what you
type.

You can type and run BASIC programs, load a `.PRG` program file from a disk,
and copy text between the C64's screen and other programs. The picture is
black and white on every display.

![A two-line BASIC program running on the Commodore 64.](shot:c64-window){full}

## Starting the Commodore 64

The program comes on a disk of its own, in a folder called `C64`. Open the
folder and double-click **C64.O88**. The folder also holds [[README.TXT]],
notes about the program, and [[COPYING]], its licence.

The C64 needs 64KB of free memory for its RAM. The ROMs are inside
C64.O88 itself, so you can copy the program anywhere and it still starts.

## How fast it is

On an IBM PC or XT the Commodore 64 runs very slowly. A 4.77 MHz 8088 runs
it at about **1%** of a real C64's speed. The machine takes a minute or two
just to reach **READY.**, and each key you type takes a second or two to
appear, because the emulated C64 reads its keyboard that seldom. Type one key
at a time and wait for it. On a 386 or 486 the C64 is usable.

The left end of the status row under the screen shows the speed: the
percentage of a real C64 (`% cpu`) and the frames per second the emulated
C64 is drawing (`fps`; a real one draws 50). Nothing limits the speed, so on
a fast machine the figure can be above 100%.

## Using BASIC

Type a line of BASIC and press `Enter` (the C64's RETURN). A line with a
number in front is stored as part of a program; a line without one runs at
once. For example:

1. Type `10 print "hello"` and press `Enter`.
2. Type `20 goto 10` and press `Enter`.
3. Type `run` and press `Enter`. Press `Esc` (RUN/STOP) to stop it.

Type in lower case. The C64 shows unshifted letters as capitals, and a
shifted letter is a graphics character, exactly as on the real keyboard.
`list` shows the program, `new` clears it.

There is no disk drive, tape drive or cartridge in this C64. `LOAD"*",8`
answers **?DEVICE NOT PRESENT ERROR**, which is what a real C64 with nothing
plugged in says. Load programs with **File > Smart attach...** instead.

![The C64 starting up, and its answer to LOAD from disk drive 8.](shot:c64-ready){full}

## The keyboard

Most keys are where you would expect. The C64 keys that have no matching
key on a PC keyboard are here:

| C64 key | PC key |
|---|---|
| RETURN | `Enter` |
| RUN/STOP | `Esc` |
| RESTORE | `Page Up` (`Esc` held with `Page Up` returns to READY.) |
| CLR/HOME | `Home` |
| INST/DEL | `Backspace` or `Delete`; `Insert` inserts |
| C= (Commodore key) | `Tab` |
| CTRL | `Ctrl` |
| SHIFT LOCK | `Caps Lock` |
| F1, F3, F5, F7 | `F1`, `F3`, `F5`, `F7` |
| F2, F4, F6, F8 | `F2`, `F4`, `F6`, `F8` |
| Left arrow key (top left) | `End` |
| Up arrow key | `Page Down` |

`Ctrl` with a digit types the C64's colour and reverse-video codes, as CTRL
with a digit does on the real machine.

## The joystick

The C64's joystick port 2 is the arrow keys, with `Ctrl` as the fire button.
Port 1 is empty. **Preferences > Swap joysticks** (`Alt-J`) moves the
joystick to port 1, for games that read that port.

Because the arrow keys are the joystick, they do not move the cursor in BASIC,
just as on a real C64 with a joystick on its keys. The two joystick symbols on
the status row light up as you move.

On a machine with no mouse, os8088 uses the arrow keys for its pointer. Press
`Scroll Lock` to give them to the C64; the status row reminds you with
**ScrollLock for joystick**.

## Loading a program

**File > Smart attach...** (`Alt-A`) opens a file dialog. Pick a `.PRG` file
and click **Open**. The program goes into the C64's memory at the address the
file names, and the status row says **Loaded** and the name. It does not start
by itself: type `run` for a BASIC program, or the `SYS` command its
instructions give.

## Copy and paste

**Edit > Copy** puts the whole 40 by 25 screen on the clipboard as text, so
you can paste it into Note Pad or any other program. It arrives in lower case.
Graphics characters come out as full stops.

**Edit > Paste** types the clipboard into the C64, ten characters at a time,
as fast as the C64 reads them. Write the text in lower case, such as
`print 2+2`; capitals arrive as graphics characters. A paste takes up to 2,048
characters (about fifty lines of BASIC). Paste is greyed while the C64 is
paused.

## Full screen

**Preferences > Fullscreen** (`Alt-D` or `Alt-Enter`) makes the window fill
the screen; the same keys bring it back, and they are the only way back,
because a full-screen window has no menu bar. On a 286 or faster the picture
is magnified: doubled both ways on VGA, doubled in width on CGA and Hercules.
On an 8088 it stays at its own size, centred, because magnifying would slow
the C64 down further.

## The File menu

| Item | Key | What it does |
|---|---|---|
| Smart attach... | `Alt-A` | Load a `.PRG` program file into memory |
| Reset machine CPU | `Alt-F9` | Reset the C64, as a reset switch would. Memory is not cleared, but BASIC starts afresh at READY. This also ends a pause |
| Power cycle machine | | Switch the C64 off and on: memory is cleared and the machine starts again from the beginning |
| Exit emulator | `Alt-Q` | Close the window |

Attach disk image, Detach datasette image, Cartridge freeze, Printer/plotter,
Activate monitor and Reset drive #8 are greyed. This C64 has no disk drive,
tape, cartridge port, printer or machine-code monitor.

## The Edit menu

| Item | Key | What it does |
|---|---|---|
| Copy | `Alt-Delete` | Copy the screen as text |
| Paste | `Alt-Insert` | Type the clipboard into the C64 |

On many PC and XT keyboards `Alt-Delete` and `Alt-Insert` do not reach the
program; use the menu.

## The Snapshot menu

Every item on the Snapshot menu is greyed. This C64 cannot save or load
snapshots, record events or save screenshots.

## The Preferences menu

![The Preferences menu, with its keys beside the items.](shot:c64-prefs){full}

| Item | Key | What it does |
|---|---|---|
| Fullscreen | `Alt-D` | Fill the screen, or go back to a window |
| Warp mode | `Alt-W` | Let the C64 run in longer stretches for more speed. A **W** lights on the status row. On an 8088 it changes nothing and says so |
| Pause emulation | `Alt-P` | Stop the C64, and start it again. A **P** lights on the status row |
| Advance frame | `Alt-Shift-P` | When paused, run the C64 for one frame of its screen and stop again. When running, pause |
| Swap joysticks | `Alt-J` | Move the joystick between port 2 and port 1 |

A `*` in front of an item means it is switched on. Show status bar and Allow
keyset joysticks are always on and cannot be switched off. Restore display
state, Emulation speed, Mouse grab and Settings... are greyed: the window is
os8088's, nothing limits the speed, there is no C64 mouse, and every setting
there is is on this menu.

## The Help menu

![The About panel.](shot:c64-about){right}

**Help > About VICE...** shows the version, the copyright of VICE and of
Commodore's ROMs, and who ported it. The C64 pauses while it is up; click to
put it away. The other Help items are greyed. The **VICE** menu beside the
apple has About VICE too, and **Close**, which closes the window.

## The status row

The row under the C64 screen shows, from the left: the speed (`% cpu` and
`fps`), the two joystick ports, the drive number `8`, and two lamps, **W** for
warp mode and **P** for pause, which light (white on black) when switched on.
Messages, such as **Paused.** or a reason something did not work, appear on
the row for a few seconds.

## Good to know

- The C64 draws its normal text screen, with the character set it is using.
  Bitmap graphics, multicolour modes and sprites are not drawn, and fine
  raster effects do not show. Games that draw with them will not look right.
- The screen is black and white on every display, VGA included. Each of the
  C64's sixteen colours becomes black or white by how bright it is.
- Sound is one plain tone through the PC speaker: the pitch of the C64's
  first sound voice. The other two voices, the waveforms and the filters are
  not played.
- The C64 is a PAL machine.
- A `.PRG` file can be at most 65,533 bytes, and must fit in the C64's memory
  from the address it names.
- Nothing is saved to disk. To keep a listing, use Edit > Copy and paste it
  into Note Pad.
