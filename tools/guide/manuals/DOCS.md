# Documents

`DOCS` is an empty folder for your own documents, on the disks of the word
processors.

## Where it is

On the Microsoft Word disk, the Word (C edition) disk and the Scribe disk,
in every size, and on every disk of the everything set. The live USB image
and CD have one too.

## Using it

When you save a new document, pick this folder in the Save As dialog to keep
your work apart from the program and its welcome document. While the program
stays open, its dialogs come back to `DOCS`. Make folders inside it if you
like.
