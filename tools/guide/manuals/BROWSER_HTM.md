# Browser manual

`BROWSER.HTM` is the Browser's own short manual, written as a web page. It
explains how to open a page, the keys for moving about, and what the
Browser refuses and why, with a link to try for each refusal.

![The Browser showing its manual page, opened from the floppy.](shot:browser-window)

## Why it is on this disk

It gives the Browser something to show on a machine with no network card.
A page on a disk needs nothing else, so it is the first page to open after
a fresh start. It is in the `MEDIA` folder of the software disks in every
size, the network disk, the first disk of the everything set, the video
demo drives and the live USB image and CD.

## Opening it

Double-click **BROWSER.HTM** and the Browser ([[BROWSER.O88]]) opens with the page
loaded. Scroll with the arrow keys, `PgUp`, `PgDn` or `Space`. The two
links under **What it refuses, and why** show two of the Browser's
messages on purpose: one is a secure `https` address and the other a link
that only works on a page fetched from a server.

The page uses the same kinds of things any page on the Browser may show: a
title, headings, a table, a list and links. Open it in Note Pad to see the
HTML it is written in.
