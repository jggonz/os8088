# Greeter demo

The Greeter is the smallest of the three Weave demo apps: a form with a name
field, a **Greet** button, a **Shout it** check box and a meter that counts
greetings up to ten. Type a name, press **Greet**, and it says hello; tick
**Shout it** and it shouts.

![The Greeter after greeting Ada three times with Shout it ticked.](shot:weave-form){full}

## What is inside it

One bundle file holding the form's layout and its script, already packed.
Its sources, [[FORM.WML]] and [[FORM.WJS]], ship beside it on the Loom disk.

## Using it

Double-click **FORM.WAB** to run it in [[WEAVE.O88]], or open it from
Weave's **Bundle** menu. The [[WEAVE.O88]] manual walks through every
control. To change it, open [[FORM.WML]] in [[LOOM.O88]], edit, and pack it
again.
