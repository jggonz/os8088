# Welcome program

`WELCOME.BAS` is a short Applesoft BASIC program for the Apple II Plus, made
for os8088. It shows off what the emulated Apple can do, one screen at a
time: the 40-column text screen with inverse text, the lo-res graphics with
sixteen bands of colour, the hi-res graphics with a fan of lines, and a
beep from the speaker. It waits for a key between screens.

![The welcome program's first screen.](shot:apple2-window)

## Where it is

In the `APPLE2` folder of the Apple II Plus disk in every size, and of the
everything set.

## Running it

Double-click **WELCOME.BAS** and the Apple II Plus ([[APPLE2.O88]]) starts with the program
loaded. Type `RUN` at the `]` prompt to run it, or `LIST` to read it.

On a 4.77 MHz XT the text screen appears two or three seconds after
`RUN`, and each graphics screen takes about a minute and a quarter,
drawing a band or a line at a time so you can watch it arrive. On a 386
it is quick. The window is black and white; **Machine > Color NTSC**
shows the lo-res bands in colour on a VGA screen.
