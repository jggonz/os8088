# Word, C edition

The `CWORD` folder holds the C edition of Microsoft Word and its welcome
document:

- `CWORD.O88`, the word processor;
- `WELCOME.RTF`, a document that shows what it can do. Double-click it to
  read it.

## Where it is

This folder is on the everything set and on the live USB image and CD. On
the program's own disk the same two files are at the top level of the disk,
beside an empty `DOCS` folder for your work.

Typefaces are not kept here: Word finds them in `SYSTEM/FONTS` on the system
disk.
