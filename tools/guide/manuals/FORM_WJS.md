# Form script

`FORM.WJS` is the Greeter's script, in Weave's small JavaScript-like
language. It says what happens when you press the buttons: **Greet**
checks that a name was typed, counts the greeting (up to ten, which fills
the meter) and answers "Hello, *name*." or, with **Shout it** ticked,
"HELLO, *name*!". **Reset** sets the count back to zero and shows an alert
that changes the line to "Reset done." when you close it.

![FORM.WJS open in Loom's script view.](shot:loom-script)

## Where it is

In the `LOOM` folder of the Weave disk and the Loom disk, in every size,
and of the second disk of the everything set. The compiled app it belongs
to is in the `WEAVE` folder beside it.

## Using it

Double-click **FORM.WJS** and Loom ([[LOOM.O88]]) opens the Greeter's project.
Click **FORM.WJS** in the list on the left, or press `Ctrl-N`, to edit the
script. The script is named in the project's markup,
[[FORM.WML]], so it travels with it when the project is packed into
[[FORM.WAB]].
