# Games

`GAMES` holds the games. Double-click one to play.

## Where it is

- **The software disk** carries a selection: WireBall, Arkanoid, Tank
  Attack, Cyclone 88, Minesweeper, Clear Skies, Missile Command, Solitaire
  and TameGram on the 360KB disk, with Dot Delirium, Pixelstein 3D,
  Gorillas, isoTron and (on the 1.2MB and 1.44MB disks) DrMarco added on the
  larger ones.
- **The system disk** carries Minesweeper in its `GAMES` folder, except at
  360KB, where there is no room for it.
- **The emulator system disk** and the everything set have one too, and the
  live USB image and CD gather every game in theirs.

The games disk has no `GAMES` folder: every game sits at the top level of
that disk, so you double-click **B:** and then a game.

## Putting things in it

Copy games in and out as you like; a game runs from any folder. High scores
are not kept here. A game that keeps them saves them in `SYSTEM/APPDATA` on
the disk it was started from, so leave that disk writable if you want your
scores kept.
