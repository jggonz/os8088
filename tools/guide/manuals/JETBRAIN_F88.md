# JetBrains Mono

JetBrains Mono is a bold fixed-width typeface designed for reading code. Its
lowercase letters are the largest of any face on the system, 7 pixels tall,
and every stroke is two pixels thick, so it stays easy to read for a long
time. It is the face to put a long listing or a log in.

![Font Viewer showing JetBrains Mono with a sample typed in.](shot:jetbrain-f88)

## Where it comes from

This face was fitted for os8088 onto the screen's grid from JetBrains Mono,
by the JetBrains Mono Project Authors, using its bold weight.

JetBrains Mono is under the SIL Open Font License 1.1, and so is this face.
`LICENSE.TXT` in the same folder carries the licence and the authors' credit.

## What is in it

One style of 95 characters: the capital and small letters, the figures and
the punctuation of plain ASCII. There are no accented letters. Every
character is 8 pixels wide, so 80 fit across a 640-pixel screen, and each
line is 14 pixels tall.

## Using it

The face lives in `SYSTEM/FONTS` on the system disk. Double-click
**JETBRAIN.F88** to look at it in Font Viewer.

Microsoft Word, the C edition of Word and Scribe list it in the **Font** box
on their ribbon as **Jetbrain**. Pick it and the whole document is shown in
it; the ribbon then names it in full, **JetBrains Mono**.
