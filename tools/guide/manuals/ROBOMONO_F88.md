# Roboto Mono

Roboto Mono is a heavy fixed-width typeface with plain, rounded letters.
Every character is 8 pixels wide, like Courier, but its lines are only 12
pixels tall, so a window holds more lines of it. It suits listings, tables
and notes where columns must line up.

![Font Viewer showing Roboto Mono with a sample typed in.](shot:robomono-f88)

## Where it comes from

This face was fitted for os8088 onto the screen's grid from Roboto Mono, by
the Roboto Mono Project Authors, using a very heavy weight because the lighter
ones came out as single-pixel lines at this size. The small `f` was redrawn
by hand so that it does not read as a `t`.

Roboto Mono is under the SIL Open Font License 1.1, and so is this face.
`LICENSE.TXT` in the same folder carries the licence and the authors' credit.

## What is in it

One style of 95 characters: the capital and small letters, the figures and
the punctuation of plain ASCII. There are no accented letters. Every
character is 8 pixels wide and each line 12 pixels tall, with no extra space
between lines.

## Using it

The face lives in `SYSTEM/FONTS` on the system disk. Double-click
**ROBOMONO.F88** to look at it in Font Viewer.

Microsoft Word, the C edition of Word and Scribe list it in the **Font** box
on their ribbon as **Robomono**. Pick it and the whole document is shown in
it; the ribbon then names it in full, **Roboto Mono**.
