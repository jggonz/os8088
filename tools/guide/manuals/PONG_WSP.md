# Pong sprites

`PONG.WSP` holds Weave Pong's two pictures, drawn as text: `BALL`, a round
ball 8 by 8 pixels, and `PAD`, a paddle 8 by 24. Each row of the picture is
a line of the file, with `#` for a lit pixel and `.` for an empty one, so
you can redraw them in any text editor.

![The ball and the paddles in the running game.](shot:weave-pong)

## Where it is

In the `LOOM` folder of the Weave disk and the Loom disk, in every size,
and of the second disk of the everything set. The compiled app it belongs
to is in the `WEAVE` folder beside it.

## Using it

A double-click does not open it. Open the project's [[PONG.WML]] in
[[LOOM.O88]] instead, and pick **PONG.WSP** in the list on the left to
edit it there. Both paddles use the same `PAD` picture, coloured
differently by the markup.
