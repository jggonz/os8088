# Weave

The `WEAVE` folder holds the Weave runtime and three demo apps, ready to run:

- `WEAVE.O88`, the runtime that runs Weave apps;
- `FORM.WAB`, `SHEET.WAB` and `PONG.WAB`, the demo apps: the Greeter form, a
  picnic budget spreadsheet and a game of Pong.

## Where it is

On the Weave disk and the Loom disk, in all four sizes, beside the `LOOM`
folder, and on the everything set and the live USB image and CD.

## Using it

Double-click a `.WAB` file to run that app in Weave. An app runs from any
folder on the disk, including the `LOOM` folder where Loom saves the apps it
builds, as long as `WEAVE.O88` stays on the disk.
