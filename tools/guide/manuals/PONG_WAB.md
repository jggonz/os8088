# Pong demo

Pong as a Weave app, for one player against the computer. You are the cyan
paddle on the left; `A` moves it up and `Z` moves it down, and **Serve**
puts the ball in play. Every return is a little faster, and a steep one off
the paddle's edge can beat the computer.

![A rally in Weave Pong.](shot:weave-pong){full}

## What is inside it

One bundle file holding the playing field, the script that serves, moves the
computer's paddle and keeps score, and the sprites. Its sources,
[[PONG.WML]], [[PONG.WJS]] and [[PONG.WSP]], ship on the Loom disk.

## Using it

Double-click **PONG.WAB** to run it in [[WEAVE.O88]]. The speaker beeps on
every hit and every point. To change the game, open [[PONG.WML]] in
[[LOOM.O88]].
