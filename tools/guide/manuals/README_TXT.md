# Read Me

`README.TXT` is the name of several different read-me files. Each one is
about the disk or the folder it sits in, and its words are shown below,
one version per disk. Double-click any of them to read it in Note Pad.

## On the system disk: the os8088 manual

The system disk's `README.TXT` is the whole manual for os8088, in twelve
short sections: the chip menu; windows, the dock and the desktop; Disk
windows; files and disks; programs; the Control Panel; drivers; linking
to a DOS PC; the hard disk and hibernation; working without a mouse; the
messages the system shows; and its limits and how to switch off. It is
the file to read first.

The same file is at the top of the system disk in every size, the emulator
system disk, the video demo drives and the live USB image and CD.

## In a program's folder or on its own disk

The other copies are notes for one program: how to start it, its keys, and
anything it needs.

- In the `C64` folder of the Commodore 64 disk and the everything set:
  notes on the Commodore 64 emulator.
- In the `APPLE2` folder of the Apple II Plus disk and the everything set:
  notes on the Apple II Plus emulator, including how fast it runs on an XT.
- At the top of the 1942 disk: the game's keys and what each screen needs.
- At the top of the PaccMan disk, and in the `PACCMAN` folder of the
  everything set: PaccMan's keys, menus and scoring, and the licence of the
  program it was ported from.
- At the top of the REDLINE disk: how to run the benchmark and read its
  views.

## On the CP/M emulator disk

The 1.2MB and 1.44MB CP/M emulator disks carry one more, in drive A's user
area 6 with the game it describes: the instructions for the 1981 CP/M game
Nemesis and Dungeon Master. Read it from inside CP/M by typing `USER 6`
and then `TYPE README.TXT`, or double-click it in the `A/6` folder to open
it in Note Pad.
