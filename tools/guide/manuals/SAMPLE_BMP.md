# Paint sample

A sample drawing for Paint, headed **os8088 Paint** and "a sample drawing -
open it, change it, save it". Below the heading are five panels, one for
each kind of shape Paint draws: **Line** (a fan of lines), **Box**, **Fill**
(a box filled with grey), **Oval** and **Free** (a freehand curve). It is a
448 by 110 black-and-white Windows bitmap.

![The sample drawing open in Paint.](shot:sample-bmp)

## Where it is

In the `MEDIA` folder of the Office disk, beside Paint, and on the live USB
image and CD.

## Opening it

Double-click **SAMPLE.BMP** and Paint ([[PAINT.O88]]) opens with the drawing. It is there
to be changed: try the tools on it, then save your version under a new
name with **File > Save as Bmp...** or **Save as Gif...**. PiXEL opens it
as well.
