# Scribe welcome (Word format)

`SCWELCOM.DOC` is Scribe's welcome document saved as a Word `.DOC` file. Its
words are the same as [[SCWELCOM.RTF]]'s: what Scribe adds to Word, how its
two file formats treat pictures, and a tour of bold, italic and underlined
text, small capitals, a hanging indent, centred and flush-right lines, a
double-spaced paragraph and a table of useful keys.

## Where it is

At the top of the Scribe disk in every size, beside `SCWELCOM.RTF`, and in
the `SCRIBE` folder of the live USB image and CD.

## Opening it

Start Scribe ([[SCRIBE.O88]]) and choose **File > Open...**, then pick
**SCWELCOM.DOC**. Double-clicking a `.DOC` file opens Microsoft Word
([[WORD.O88]]) when it is on the machine, and Word reads this file too.
