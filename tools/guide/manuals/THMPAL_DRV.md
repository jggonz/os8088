# Color theme presets

`THMPAL.DRV` is the **Color Theme** window, which the Control Panel opens
with the **Customize...** button on its Theme page. It offers eight colour
schemes for the Color theme and a choice of title bar style.

![The Color Theme window.](shot:thmpal-drv-window){right}

## What is inside it

The window itself and the eight schemes with their names. The system reads
the file when you press **Customize...**, keeps it while the Control Panel
is open, and frees it when you close the Control Panel. The schemes are not
kept in memory the rest of the time; the one you choose is remembered on its
own.

## Using it

Open the **Control Panel**, choose its **Theme** page and press
**Customize...**. The button works on a VGA or EGA screen and is greyed on
Hercules and CGA, which cannot show the Color theme.

Click a scheme in the list and the whole screen changes to it at once, so
you can look before you decide:

| Scheme | Desktop and title bars |
|---|---|
| **Classic** | Teal desktop, blue title bars: the Color theme as it first was |
| **Workbench** | Light blue desktop, blue title bars |
| **Light** | Light grey desktop, cyan title bars |
| **Forest** | Light green desktop, green title bars |
| **Amethyst** | Light magenta desktop, purple title bars |
| **Amber** | Yellow desktop, brown title bars |
| **Midnight** | Dark blue desktop, dark grey title bars |
| **Desert** | Brown desktop, red title bars |

**Title bar style** chooses how an active title bar is drawn: **Solid**,
**Stripes** (with pinstripes), or **Windows**, which gives every window the
buttons and click-open menus of the Windows theme in the colours of your
scheme. The **95** box, next to Windows, puts back the grey buttons of the
plain Windows theme.

**Apply** keeps what you see. **Cancel**, **Esc** or the close box put back
the scheme and style you started with. Close the Control Panel to save your
choice to the system disk.

![Forest, previewed while the window is still open.](shot:thmpal-drv-forest)

## Good to know

- Choosing a scheme switches the theme to Color, whichever theme was in use
  before. Cancel puts that theme back too.
- The schemes colour the desktop, the menus and the title bars. The inside
  of every window stays black on white.
- If the file cannot be read when you press Customize..., the menu bar says
  why. The system disk must be in drive A:.
