# WIN16

WIN16 runs programs written for Windows 3.0 in os8088 windows. A Windows
program opens in a window of its own, with its menu bar, its dialogs, its
buttons and lists and its own icon, drawn the way Windows 3.0 drew them on
the same display and in that display's Windows System font.

No Windows files come with os8088. WIN16 runs programs you bring: Windows
3.0's Minesweeper, Calculator, Clock and Reversi, and programs like them.
Windows itself is never needed and never run.

## Starting a Windows program

Double-click the program's `.EXE` file in a Disk window. [[DOS.O88]] opens
it, sees from its header that it is a Windows program, and hands it to WIN16
before anything else runs. On Windows the same file would print *This
program requires Microsoft Windows.* when run from DOS; here it opens.

WIN16.O88 must be on a disk in a drive when you do this. If it is not, the
machine says **Needs WIN16.O88**. Double-clicking WIN16.O88 itself opens a
window that says what it is for and nothing more.

Each Windows program is a window of its own, so you can run two at once,
for example Minesweeper beside Calculator, and beside any os8088 program.
The menu bar, the dock and the Task Manager name each one after the
program, such as **WINMINE** or **CALC**.

## Closing a program

Click the window's close box, or choose **Exit** on the program's own menu.
The program decides, as it did on Windows: a program with unsaved work may
ask first.

If a program does not close, click the close box a second time. WIN16 asks
**It has not closed. End it?** Choose **Proceed** to end it there and give
back all of its memory, or **Cancel** to ask it once more. A program that
never stops to wait for you cannot be ended this way.

## Opening and saving files

A Windows program's **Open** and **Save As** commands show os8088's own file
dialog, the one every os8088 program uses, in place of the Windows one. Pick
a file, or type a name in the Save form, and the program goes on with it;
**Cancel** goes back to the program with nothing chosen. A program that
names a usual extension, such as Notepad's `.TXT`, adds it to a name typed
without one. Printing is not available: a program's Print command is greyed,
as it is on a Windows with no printer.

## Fonts and colours

A program's **Font** command, such as Clock's **Set Font** or the Marquee
screen saver's **Format Text**, shows a list of the two faces WIN16 has:
**MS Sans Serif** and **System**. Choose one and press **OK**, or
double-click it, and the program draws its text in that face. Each face
comes in one size. A program that asks for a colour gets a list of the
sixteen Windows colours by name.

## Settings

A program's `WIN.INI` entries and its own `.INI` file are kept in the
`SYSTEM\APPDATA\WIN16` folder on the disk WIN16.O88 was started from. They
are written when the program ends, so its high scores and options are there
the next time. Two programs that write the same file both keep what they
wrote. On a disk without that folder, a program's settings last until it
closes.

The file types a program registers, such as Cardfile's `.CRD`, are kept in
`REG.DAT` in the same folder.

Programs that offer to link or embed objects from other programs (OLE) run
with those commands greyed. A Cardfile card or Write document that holds
such an object opens without it.

A program can read files packed by Microsoft's `COMPRESS`, whose names end
in `_`, such as `CTL3D.DL_`: it is given what they unpack to. A file a
program installs for every program to share goes in the same
`SYSTEM\APPDATA\WIN16` folder.

When a program opens a document in another program, such as a setup
program showing its `README.TXT`, the document opens in the os8088
program that opens it when you double-click it. A Windows program opened
this way starts in a WIN16 window of its own.

## Paint programs

Paint programs such as Windows 3.0's Paintbrush draw as they did on
Windows: brush strokes, lines, boxes and filled shapes stay in the picture,
lines are as wide as the width chosen, the roller fills an area with the
chosen colour, and the text tool types. **File > Save As** writes a `.BMP`
file and **File > Open** reads one back. When memory runs short,
Paintbrush keeps the parts of the picture it is not showing in its own
temporary file, as it did on Windows.

Windows 3.1's Paintbrush runs as well, but it saves a picture through one
block of memory the size of the whole picture. A full-screen picture needs
more than a 640 KB machine has free beside the program, and Paintbrush says
**Not enough memory for this operation.** Make the picture smaller before
drawing in it, with **Options > Image Attributes** (320 x 200 pixels
saves).

## What it can run

| The program | What WIN16 does |
|---|---|
| A Windows 3.0 program, or a 3.1 program that runs in real mode | Runs it. Most of a program's code is loaded only when it is first used, and is put away again when memory runs short, as Windows did |
| A program using the 80186's instructions | Runs it on a V20, an 80186 or better; on an 8088 it says **Needs a V20, 80186 or better.** |
| A program using floating point | Runs it; no maths chip is needed |
| A program with its own libraries, such as Recorder's `RECORDER.DLL` | Runs it with each `.DLL` from the program's own folder, or from the `SYSTEM\APPDATA\WIN16` folder where a setup program puts the files it shares, or from the folder the program names. A library that is not there stops the program when it is first called, with the call's name, such as **Needs RECORDER.17**; one that fails to start says **A library it needs did not start.** |
| A Windows 3.1 program made for protected mode only | **It needs protected mode.** |
| A `.DLL` opened on its own | **A Windows library, not a program.** |

A program that calls something WIN16 does not have yet is closed when it
calls it, with the name of what it asked for, such as **Needs USER.182,
which WIN16 does not provide yet.**

## Good to know

- WIN16 works on VGA, EGA, CGA and Hercules, with each card's own Windows
  System font.
- Each program takes its own memory. How many run at once depends on the
  free memory; one that does not fit says **Not enough memory to load it.**
  One that runs out of room for the next part of its own code is closed
  with **Not enough memory for its code.**
- It is not on the disks for the smallest, 128KB machines. On a machine
  running os8088's protected-mode system it says **WIN16 needs real mode**.
- [[WIN16.TXT]] has notes on the program and [[COPYING.W16]] is its licence.
