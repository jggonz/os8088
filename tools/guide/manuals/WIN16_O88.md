# WIN16

WIN16 runs programs written for Windows 3.0 in os8088 windows. A Windows
program opens in a window of its own, with its menu bar, its dialogs, its
buttons and lists and its own icon, drawn the way Windows 3.0 drew them on
the same display and in that display's Windows System font.

No Windows files come with os8088. WIN16 runs programs you bring: Windows
3.0's Minesweeper, Calculator, Clock and Reversi, and programs like them.
Windows itself is never needed and never run.

## Starting a Windows program

Double-click the program's `.EXE` file in a Disk window. [[DOS.O88]] opens
it, sees from its header that it is a Windows program, and hands it to WIN16
before anything else runs. On Windows the same file would print *This
program requires Microsoft Windows.* when run from DOS; here it opens.

WIN16.O88 must be on a disk in a drive when you do this. If it is not, the
machine says **Needs WIN16.O88**. Double-clicking WIN16.O88 itself opens a
window that says what it is for and nothing more.

Each Windows program is a window of its own, so you can run two at once,
for example Minesweeper beside Calculator, and beside any os8088 program.
The menu bar, the dock and the Task Manager name each one after the
program, such as **WINMINE** or **CALC**.

## Closing a program

Click the window's close box, or choose **Exit** on the program's own menu.
The program decides, as it did on Windows: a program with unsaved work may
ask first.

If a program does not close, click the close box a second time. WIN16 asks
**It has not closed. End it?** Choose **Proceed** to end it there and give
back all of its memory, or **Cancel** to ask it once more. A program that
never stops to wait for you cannot be ended this way.

## Settings

A program's `WIN.INI` entries and its own `.INI` file are kept in the
`SYSTEM\APPDATA\WIN16` folder on the disk WIN16.O88 was started from. They
are written when the program ends, so its high scores and options are there
the next time. Two programs that write the same file both keep what they
wrote. On a disk without that folder, a program's settings last until it
closes.

## What it can run

| The program | What WIN16 does |
|---|---|
| A Windows 3.0 program up to 64KB | Runs it |
| A program using the 80186's instructions | Runs it on a V20, an 80186 or better; on an 8088 it says **Needs a V20, 80186 or better.** |
| A program using floating point | Runs it; no maths chip is needed |
| A program over 64KB | **Larger than 64KB: not yet.** |
| A Windows 3.1 program made for protected mode only | **It needs protected mode.** |
| A `.DLL` or other library | **A Windows library, not a program.** |

A program that calls something WIN16 does not have yet is closed when it
calls it, with the name of what it asked for, such as **Needs USER.182,
which WIN16 does not provide yet.**

## Good to know

- WIN16 works on VGA, EGA, CGA and Hercules, with each card's own Windows
  System font.
- Each program takes its own memory. How many run at once depends on the
  free memory; one that does not fit says **Not enough memory to load it.**
- It is not on the disks for the smallest, 128KB machines. On a machine
  running os8088's protected-mode system it says **WIN16 needs real mode**.
- [[WIN16.TXT]] has notes on the program and [[COPYING.W16]] is its licence.
