# Catalog

`CATALOG.TXT` is the guide to the Weave disk: what is in the `WEAVE` and
`LOOM` folders, what each of the three demo apps shows off, which source
files each was built from, and how to run, edit and repack them. Its words
are shown below.

## Where it is

At the top of the Weave disk in every size. The copies differ only in
their last line, which names the size of the disk.

## Using it

Double-click it to read it in Note Pad. The short version: open the
`WEAVE` folder and double-click a `.WAB` to run an app, or open the `LOOM`
folder and double-click a `.WML` to edit one in Loom, where `^P` packs a
new bundle beside the sources.
