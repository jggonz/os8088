# Sample paper

`PAPER.TEX` is a short sample working paper for TeXPad, called *A Compact
Measure for Working Papers*. It has a title block, an abstract, numbered
sections and subsections, a ruled table of chips (an 8088, an 8259A and
2764 EPROMs), a quotation, a page break and a bulleted list, and it
typesets to two pages.

![TeXPad with the sample paper: source on the left, page 1 on the right.](shot:texpad-window)

## Where it is

In the `MEDIA` folder of the software disks in every size, the Office disk,
the first disk of the everything set, the video demo drives and the live
USB image and CD.

## Using it

Double-click **PAPER.TEX** and TeXPad ([[TEXPAD.O88]]) opens with it typeset.
`PgDn` turns to the second page. The text of the paper describes TeXPad
itself: its paper sizes and margins, how tables are set, and how
**File > Export PDF** and **Export PS** write a file a modern computer can
print.

It is a good document to try the Layout menu on: change the margins or
padding and watch the pages reflow. For the markup itself, open
[[GUIDE.TEX]].
