# Pictures

`PICTURES` holds sample pictures for PiXEL, in a mix of formats: photographs
as JPEG, two GIF pictures, PNG images, a Windows bitmap and a
PCX file. They show what PiXEL can open and how it handles each kind.

## Where it is

At the top of the disk, on the disks that carry PiXEL and have room for its
pictures. The PiXEL disk, the live USB image and CD and the VGA and CGA video
demo hard disks have the whole set of ten. The second 720KB software disk and
the everything sets carry five of them. The 1.44MB and 1.2MB software disks
have PiXEL but no room for the pictures; use the PiXEL disk for those.

## Using it

Double-click a picture to open it in PiXEL. PiXEL also opens pictures from
any other folder or disk, and you can save your own work here as long as the
disk has room.
