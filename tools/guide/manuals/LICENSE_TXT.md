# Font licence

`LICENSE.TXT` lists the typefaces in the system's `FONTS` folder, where each
one came from, and the licence they are shared under. Its words are shown
below.

## What it says

The `FONTS` folder holds ten families. Two were drawn for os8088: Charter,
by hand, and TallX, from the system's own 8 by 8 screen font. The other
eight were fitted, letter by letter, onto os8088's pixel grid from free
outline typefaces that other people designed. Those eight are shared under
the SIL Open Font License 1.1, which asks that its notice travel with
anything made from the fonts. This file is that notice: it names each
face, the typeface it was fitted from, and its copyright holders.

## Where it is

In `SYSTEM/FONTS` on the system disk in every size, the emulator system
disk, the video demo drives and the live USB image and CD, beside the
typefaces it describes.

## Using it

Double-click it to read it in Note Pad. Keep it with the fonts if you copy
them to another disk: the licence asks for that. Font Viewer shows the
typefaces themselves.
