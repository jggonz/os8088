# Form markup

`FORM.WML` lays out the Greeter, the smallest working Weave app: a heading,
a box for your name, a **Greet** button, a **Shout it** tick box, a line
that answers you, a meter counting the greetings, a **Reset** button and a
**Party** menu. It is written in Weave markup, a small HTML-like language,
and it is the main file of the Greeter's project.

![FORM.WML open in Loom, with the project's files listed on the left.](shot:loom-window)

## Where it is

In the `LOOM` folder of the Weave disk and the Loom disk, in every size,
and of the second disk of the everything set. The compiled app it belongs
to is in the `WEAVE` folder beside it.

## Using it

Double-click **FORM.WML** and Loom ([[LOOM.O88]]) opens the project, with this
file in the editor and [[FORM.WJS]] beside it in the list. Change a label
or add a control, then pack the project to make a new app. The packed
result of these sources is [[FORM.WAB]], which runs in Weave.

Its comment at the top lists what it demonstrates, so it is the file to
copy when you start an app of your own.
