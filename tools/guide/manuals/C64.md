# Commodore 64

The `C64` folder holds the Commodore 64 emulator:

- `C64.O88`, the emulator, with the Commodore's ROMs built in;
- `README.TXT`, notes on the program;
- `COPYING`, its licence.

## Where it is

On the Commodore 64 disk in all four sizes, on the everything set, and on the
live USB image and CD.

Double-click `C64.O88` to start it. Because the ROMs are inside the program,
`C64.O88` still starts if it is copied somewhere on its own, but the notes
and the licence belong with it.
